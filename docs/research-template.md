# 맛집 조사 템플릿

효창공원앞역 반경 500m(직선) 안의 외국인 친화 맛집을 직접 가서 확인할 때 쓰는 체크리스트예요.
한 곳을 끝내면 아래 "진행표"에 한 줄을 추가하고, 내용은 `data/restaurants.ts`에 같은 형식으로 넣어요.

## 목표

- 총 30곳: 한식·분식·고기·국수 약 20곳, 카페 약 5곳, 술집 약 5곳
- 주별 할당량: 1주 6곳 / 2주 8곳 / 3주 8곳 / 4주 8곳. 4주차 말까지 30곳을 끝내요.
- 사진과 글은 직접 찍고 직접 쓴 것만 넣어요(블로그·리뷰 사진 복사 금지).

## 가기 전 (집에서 10분)

- [ ] 네이버 지도에서 가게를 찾고 **플레이스 주소**를 복사해요(`https://map.naver.com/p/entry/place/숫자` 형태)
- [ ] 좌표 확인: 지도에서 가게를 길게 눌러 위도·경도를 받아요. 역(37.53934, 126.96139)에서 500m 안인지 봐요(빌드 검사에서도 걸러져요).
- [ ] 영업시간·휴무일을 미리 보고, 열려 있는 시간에 가요.

## 가서 확인할 것 (30~60분)

태그는 **직접 확인한 것만** 붙여요. 애매하면 붙이지 않아요.

| 태그 | 붙이는 기준 |
| --- | --- |
| `englishMenu` 영어 메뉴 | 영어 메뉴판이나 영어 병기 메뉴가 실제로 있음(번역 앱 필요 없음) |
| `card` 카드 결제 | 카드 결제 가능. 가능하면 해외 카드(Visa/Master)도 되는지 물어봐요 |
| `solo` 1인 주문 | 1인분 주문이 되고 혼자 앉을 자리가 있음(고깃집 "2인분부터"면 X) |
| `vegetarian` 채식 옵션 | 고기·해산물·멸치 육수 없이 먹을 수 있는 메뉴 1개 이상, **직원에게 확인함** |
| `spicy` 매운 음식 | 대표 메뉴가 매움(안 매운 메뉴가 있으면 주문 팁에 적기) |
| `lateNight` 늦게까지 | 22:00 이후에도 영업 |

- [ ] 대표 메뉴 2~4개: 한국어 이름, 영어 이름(무슨 음식인지 짧게), 가격(원)
- [ ] 가격대: 1 = 1인 ~1만 원, 2 = ~2만 원, 3 = 3만 원 이상
- [ ] 영업시간과 휴무일(가게에 붙은 안내 기준)
- [ ] 주문 팁 1~2문장: 주문 방법(키오스크·카운터·자리), 최소 주문, 셀프 반찬, 신분증 등
- [ ] 사진 1~3장: 대표 메뉴 1장 + 간판(찾기 쉽게) 1장. 다른 손님 얼굴이 나오지 않게. 가게 안 촬영은 직원에게 먼저 물어봐요.
- [ ] 가게 근처 동네 이름(효창동, 용문시장, 원효로 등)

## 다녀와서 (20분)

- [ ] 영어 문장을 다시 읽어요. 메뉴 설명이 맞는지, 알레르기·채식 정보가 정확한지 확인해요.
- [ ] 사진 파일 이름을 `{id}-1.jpg`, `{id}-2.jpg`로 바꿔요. `id`는 영어 소문자와 하이픈(예: `yongmun-gukbap`)이에요.
- [ ] 아래 형식으로 `data/restaurants.ts`에 추가하고 `checkedAt`에 다녀온 날짜를 넣어요.

```ts
{
  id: "yongmun-gukbap",
  name: { en: "Yongmun Gukbap", ko: "용문국밥" },
  category: "korean", // korean | snack | bbq | noodle | cafe | bar
  area: { en: "Yongmun Market", ko: "용문시장" },
  lat: 37.0,
  lng: 126.0,
  price: 1,
  hours: { en: "07:00–22:00, closed Mondays", ko: "07:00–22:00, 월요일 휴무" },
  menu: [{ name: { en: "Pork rice soup", ko: "돼지국밥" }, priceKrw: 10000 }],
  tip: { en: "…", ko: "…" },
  tags: ["card", "solo"],
  checkedAt: "2026-11-15",
},
```

(위 예시의 가게 이름과 좌표는 형식 예시일 뿐 실제 가게가 아니에요.)
